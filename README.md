# Design Patterns Notes

A clean, static study notebook for learning and revisiting common software design patterns. The repository is published with GitHub Pages and contains short, organized notes with examples, tradeoffs, and implementation ideas.

## Live Page

Visit the published site here:

[https://sadikul1500.github.io/](https://sadikul1500.github.io/)

## About This Repository

This project collects design pattern notes in a simple website format. Each pattern has its own HTML page, making the notebook easy to browse, share, and expand over time.

The notes are organized around practical learning:

- Clear explanations of each pattern's purpose
- Problem-focused examples
- Advantages, limitations, and use cases
- Separate pages for individual patterns
- Lightweight static files that work directly with GitHub Pages

## Included Topics

The notebook currently includes notes on creational and structural design patterns, including:

- Factory Pattern
- Abstract Factory Pattern
- Builder Pattern
- Prototype Pattern
- Singleton Pattern
- Adapter Pattern
- Composite Pattern
- Decorator Pattern
- Facade Pattern
- Proxy Pattern
- Chain of Responsibility Pattern

## How To Use

Open the live page link above to browse the notebook online. For local viewing, open `index.html` in a browser and navigate through the pattern pages.

## Goal

The goal of this repository is to keep design pattern learning concise, accessible, and well organized, so the notes can work both as a study guide and as a quick reference while practicing software design.
